# Auto-My-Sh Personal Assistant

## Technologies Used

- Vite Plus Monorepo
- PNPM
- Cloudflare CLI (`cf`; one `cloudflare.config.ts` per Worker)
- Cloudflare Durable Objects
- Drizzle ORM (Durable Object SQLite)
- Cloudflare Agents SDK
- Cloudflare Workers AI (`@cf/zai-org/glm-4.7-flash`)
- Pi Durable
- Telegram
- TanStack Start
- TanStack Query
- TanStack DB
- Shadcn UI (Base UI)

## Features

- Chat
- Scheduled instructions
- Todos
